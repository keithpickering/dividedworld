# An accessible path costs what the obstacle costs

Incident. In the core-loop design session of 2026-10-28 (docs/plans/2026-10-28-core-loop-design.md), the first
draft of the Whoops! card gave keyboard and screen-reader users a "wash it off" control that cleared the ink at once:
an accessibility path that skipped the card's whole cost. The owner caught it.

The owner's words. "The inconvenience must remain, so we should have a timer of some kind. It should not feel like a straightforward option to exploit accessibility features to get through things that are *supposed* to be tough to get through. There is a delicate balance to strike here, because accessibility is about maximizing usability, and a game (as opposed to a website) is about striking a balance between usability and difficulty. Any standard that prioritizes accessibility in a traditional sense will always lead toward 100% usability, 0% difficulty, which for a game is undesirable" (the owner, 2026-10-28).
