# KayfaBB never knows which instance it runs

Incident. Decided in the design session of 2026-10-28 (docs/plans/2026-10-28-kit-step-1-design.md), before any code existed: the owner asked for the system to be an engine other groups could fork, with Divided World as its first instance, and chose to keep both in one repository until the engine is published.

The owner's words. "We would do well to design the underlying system as 'KayfaBB', an open source baseline that could be forked into other instances for other groups of friends." And, choosing one repository now and two later: "I think that's fine, but I do eventually want it split up so that our repo is not actually maintaining other communities" (the owner, 2026-10-28).
