# A response never proves a private fact

Incident. Widened in the design session of 2026-10-28 (docs/plans/2026-10-28-kit-step-1-design.md) from currents' rule "Never answer whether an address has an account" (carried at f6aa96d), whose reasoning, that a message varying with a private fact is a way of reading that fact, is the kayfabe separation this game is built on.

Incident. Reworded in the design session of 2026-10-29 (docs/plans/2026-10-29-clues-design.md) from "A response never varies with a private fact", under the rule "A rule that fights the product is asked about, not obeyed into a worse product". PR #9's build, following the old wording, withheld a thread's view count from every player (#12), because a count of players could show two masks were one, and made the avatars bucket private (#13), because a file's write time could date two masks' avatars to one sitting. The owner's answers moved the line from anything that varies with a private fact to anything computed from one: a clue a player can reason from is play, and proof is what the system never gives. The design session asked where The System's settled sums fall, since the settlement counts one vote per player and a very quiet window's sum can still be read; the owner chose to name them as the one exception, as the core-loop design had accepted them (docs/plans/2026-10-28-core-loop-design.md, section 4).

The owner's words. From the spec the owner brought: "No public UI or API payload ever exposes which User owns which Character." And on what the game is: "the game might actually be more fun if it's kept that way, so you're always wondering if a character is a person you know" (the owner, 2026-10-28).

The owner's words. "There was never any direct evidence that somebody was using multiple accounts, but there are signs: \"one person leaves a room and another enters\", so to speak. You never see Superman and Clark Kent in the same room together. This is really another element of the game: the mystery of who is behind each character, the clues that can lead us to figure it out. Preserving the anonymity of a player isn't something we're doing because something awful will happen if they are found out; it's something we're doing because it adds an element of strategy and mystique, something to chew on" (the owner, on #12, 2026-10-29).

The owner's words. "we don't need to necessarily stop this detective work from happening, as long as it's always deduction, never 100% provable - being able to observe something like this is itself a source of controversy, I.e. interesting discussion" (the owner, on #13, 2026-10-29).
