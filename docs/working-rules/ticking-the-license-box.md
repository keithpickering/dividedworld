# Ticking the license box

Incident. The licensing build (`docs/plans/2026-11-25-licensing-plan.md`) added a checkbox to the PR template, "I
license this contribution under the terms of the folders it changes (see CONTRIBUTING.md)". On 2026-11-26 the build
sessions a coordinating session had dispatched were opening PRs with the box unticked, because it reads as a statement
the person licensing the work makes, and no session would make it on the owner's behalf unasked. The coordinating
session asked whether sessions should keep leaving it for the owner. The permission is held to the material it was
given for: work a session makes for the owner, under the folders' regular terms. Material someone made with other
terms in mind stays the owner's to declare.

The owner's words. "License checkbox can be checked by sessions unless a PR contains new material created by me or
someone else that was not intended to be distributed under the regular site license." (the owner, 2026-11-26).
