# The Technician design session's mocks

Record, written 2026-10-30. The mocks the Technician design session (`docs/plans/2026-10-30-technician-design.md`)
drew with the owner. Each is one self-contained HTML file, loading Anton and Barlow Condensed from Google Fonts, in the
glass's look as the two-worlds boards (`docs/research/2026-10-29-two-worlds/`) draw it.

- `q2-colors.html`: three ways to fit a fifth class's color. The owner chose A: the Technician takes the green the
  React picker's Calm already wears, and the Lurker takes purple.
- `q3-turn-classes.html`: the Turn modal's Choose a class at five classes and at ten, three ways: a carousel, a select
  screen and the full cards wrapped, each with a phone's view where it differs.
- `q3-full-carousel.html` and `q3-full-select.html`: the first two in the whole Turn modal, built on the 06 turn board
  with only Choose a class changed. The owner chose the carousel: "Carousel keeps what I like most about the current
  design", with Lurker moved to the end of the order.
- `06-turn-carousel.html`: the 06 turn board redrawn as the owner approved it: the carousel of five in the order Face,
  Heel, Jabroni, Technician, Lurker, the Lurker purple and peeking, the Technician's name set smaller to clear its
  radio. The build copies it over `docs/research/2026-10-29-two-worlds/06-turn.html` (the plan's Task 5).
