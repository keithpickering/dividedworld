# The screens design session's mockups and prototypes

Record, written 2026-10-29. What the screens design session (`docs/plans/2026-10-29-screens-design.md`) showed the
owner, one file per question, as each stood when the owner decided it. They are references for the build sessions, not
code to copy: the plans say what is built. Open any of them in a browser; each is one self-contained HTML file.

- `mock-q2-frame.html`: three frames; the owner chose B, the HUD docked at the bottom.
- `mock-q3-orbs.html`: the orbs between settlements; B, the live ghost fill (now an estimate, Q11b).
- `mock-q4-postbit.html`: standing on the postbit; B, a rank with pips.
- `mock-q5-reactions.html`: reactions; A, chips and the 2×2 quadrant picker.
- `mock-q6-composer.html`: the composer; A, quick reply with an in-place preview.
- `mock-q10-spin.html`: spinning a thread from an Act, and the ORIGIN box.
- `mock-q11-log.html`: the player's own log, a ledger by settlement.
- `mock-q12-vending.html`: the Vending Machine; A, the drawn machine, and the hand in the HUD.
- `mock-q16-characters.html` and `mock-q16b-avatars.html`: My characters, the Turn modal, the two-crop avatar.
- `mock-q18-index.html`: the index with The System's board, and a thread list.
- `mock-q19-profile-reveal.html`: a character's profile and one post of the season reveal.
- `proto-q14-stick-around.html`: Stick Around working, round 6: gravity between two holds, the eased-in pull with a
  rubber-band landing, and breaking free with a slingshot (cocked by distance, fired by a fierce release read along the
  finger's arc), a handle for a mouse, the wheel's flick, the BREAK FREE button, and a tuning panel. Rounds 1 to 3
  measured a struggle meter; the owner replaced it with the flick and then the slingshot (design, section 10).
- `proto-q15-whoops.html`: Whoops! working, round 3: the seeded splat, the fixed scaled layout, reader scrubs and the
  author's wash and ink, the color picker with shading by the ink's luminance, stacking, and the accessible sweep. Its
  default is the owner's choice, a stroke scrubbing the top layer.

The owner's own CodePen prototypes, which the session started from, are not copied here; the owner said of them: "Do
not feel compelled to use these prototypes' code or appearance verbatim, they are very old."
