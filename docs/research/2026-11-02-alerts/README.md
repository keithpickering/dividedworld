# The alerts design session's boards

Record, written 2026-11-02. The boards the alerts design session (issue #81) drew with the owner, in the style of
`docs/research/2026-10-29-two-worlds/`: each is one self-contained HTML file at a fixed size, loading Anton and Barlow
Condensed from Google Fonts. They are references for the look, not code to copy. The design and plan they belong to
are `docs/plans/2026-11-02-alerts-design.md` and its plan, written after these boards.

- `01-board-toasts.html`: the game screen with the hand closed, the HUD's new Alerts button above Hand, and a column
  of three toasts rising above the seam, with "+2 more".
- `02-alerts.html`: the Alerts page in the pause menu: filters by character, "new since you last looked", and earlier.
- `03-updates.html`: the Updates page: one update as a developer-persona blog post with its plain changelog, and the
  archive beside it.
- `04-season-news.html`: Rankings grown into the season page, its News tab open.
- `05-phone.html`: all four on a phone, 390 by 844, side by side.
