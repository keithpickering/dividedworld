This is Divided World. It looks like a message board from 2003, and it is one. It is also a game. You'll play several characters, each behind a mask, each with a secret class that decides which reactions make it stronger. No other player can see which masks are yours.

Everything anyone does here is public. Who's doing it isn't. Work it out, or don't.

How the board and the glass look and move. None of it changes how the game plays.

THEME

The 2003 board stays 2003 whichever you choose. Only its colors swap.

MOTION

Reduced stops the drifting smoke, the pulses and the orb shine. A card's effect stays: Stick Around still snaps you back, only instantly.

TEXT SIZE

Applies to the board and the glass together. Past 150% the glass folds into one column, and nothing is cut off.
