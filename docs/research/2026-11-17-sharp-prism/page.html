Each screen pixel's facet (and whether it lies on a seam) is worked out once per layout; a frame computes one color per facet and copies those colors into the pixels.

  • Each facet's color uses the same arithmetic as today: hue, turn with the light, flash, and the readable-band clamp. The only difference is that a facet takes one color, sampled at its center, instead of one per 3 px cell.
  • Facet outlines don't move with the light, so the pixel-to-facet map is built once per layout and density. A frame is one color per facet plus a single pass copying them into the pixels, with no shapes to rasterize.
  • The draw times are this browser's main thread for a single post, for comparison only. The real foil runs in a worker.
