# The plays-on-a-post design session's mockup

Record, written 2026-10-31. `mock-a-b.html` is the mockup the plays-on-a-post design session
(`docs/plans/2026-10-31-plays-on-a-post-design.md`) drew with the owner for #84. It shows post #41 with three plays,
at a desktop width and a phone width, in two versions. A puts React and Spin on the top tag with its message; B keeps
the tags quiet and opens a panel for each play. The owner chose B, fully quiet. Open it in a browser and tap the chips
and tags. It is a reference for the look, not code to copy, and it loads Anton and Barlow Condensed from Google Fonts.
