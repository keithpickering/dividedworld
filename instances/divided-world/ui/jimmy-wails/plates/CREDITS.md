# Credits for Jimmy Wails's plates

The pictures in this folder are photographs of Jimmy Wales, cropped from the banners of Wikipedia's fundraising appeals
with the appeals' text painted out. The Wikimedia Foundation published each photograph on Wikimedia Commons under the
Creative Commons Attribution-ShareAlike 3.0 Unported license, and each file here is an adaptation under that same
license. Nothing else in this repository is licensed by this notice. `../plates.ts` carries the same credit for each
plate, the banner shows it under the picture, and `../plates.test.tsx` holds this file to it.

The photographs were matched to their Commons pages by eye on 2026-11-12. The crops and fades were the Wikimedia
Foundation's, made for its banners; painting the text out was done for Minus World. The photographers do not endorse
this game or any appeal a player writes on a banner.
