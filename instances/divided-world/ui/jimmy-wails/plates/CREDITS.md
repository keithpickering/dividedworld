# Credits for Jimmy Wails's plates

The pictures in this folder are photographs of Jimmy Wales from the shoots behind Wikipedia's fundraising appeals. The
first three are cropped from the appeals' banners with their text painted out; the six after them were cropped and faded
here from the photographs themselves, by `make.py`. The Wikimedia Foundation published each photograph on Wikimedia Commons under the
Creative Commons Attribution-ShareAlike 3.0 Unported license, and each file here is an adaptation under that same
license. Nothing else in this repository is licensed by this notice. `../plates.ts` carries the same credit for each
plate, the banner shows it under the picture, and `../plates.test.tsx` holds this file to it.
